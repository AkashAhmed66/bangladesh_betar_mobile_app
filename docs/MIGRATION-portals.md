# News, Watch and Clips migration

The native portal screens now use the same Laravel v1 resources as the web portals. The route dispatcher keeps the web paths so deep links can be opened from notifications and shared navigation.

| Web route                                                                          | Native route and behavior                                                                                                                                                                                                          |
| ---------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/news`                                                                            | `NewsScreen` newsroom home: dated newsroom header, featured lead, selected stories, more updates, latest stories, most-read/most-watched rankings, filters and pull-to-refresh.                                                                                                                |
| `/news/latest`                                                                     | Paginated latest story grid.                                                                                                                                                                                                       |
| `/news/category/[category]`                                                        | Paginated category grid; category labels and fields use the API's English/Bangla values.                                                                                                                                           |
| `/news/search`                                                                     | Search input, query and paginated results.                                                                                                                                                                                         |
| `/news/[slug]`                                                                     | Article detail, view counter (`POST /news/{slug}/view`), publication metadata, bilingual body, context quote, highlights, reactions, share and media gallery. Gallery supports image, native video/audio, YouTube/document external opening and type/item navigation.               |
| `/news/about`, `/contact`, `/advertise`, `/privacy`, `/terms`, `/editorial-policy` | Static information pages available through the same `NewsScreen` route parser.                                                                                                                                                     |
| `/watch`                                                                           | Featured Watch hero, live-TV promotion and the nine editorial shelves used by the web portal (new release, trending, documentaries, popular programmes, comedy, living and culture, horror, news/current affairs and crime drama). |
| `/watch/categories`                                                                | API-backed category tiles and programme counts.                                                                                                                                                                                    |
| `/watch/category/[category]`                                                       | Paginated category grid.                                                                                                                                                                                                           |
| `/watch/[slug]`                                                                    | Show hero, trailer, premium/login gate, watchlist, metadata (genres, credits, cast, language), episode selection/player and episode reviews/ratings.                                                                               |
| `/watch/watchlist`                                                                 | Authenticated saved shows/episodes list.                                                                                                                                                                                           |
| `/watch/live` and `/watch/live/[id]`                                                | LiveKit-backed live television screen with channel selection, premium/login gating, native WebRTC video/audio, mute, reconnect, off-air and room cleanup states.                                                                    |
| `/watch/clips`                                                                     | Full-height paged clip carousel. Only the active page is allowed to autoplay; playback pauses when it leaves view. Reactions use `/reactions/watch_clip/{id}` and sharing uses the native share sheet without inventing a URL.     |

## Deliberate native constraints

- Web-only iframe/PDF rendering has no reliable React Native equivalent. YouTube and documents therefore open the supplied server URL using the device browser; the URL is never synthesized.
- Web pointer/wheel gestures are represented by `FlatList` paging and native previous/next controls. Active clip autoplay and loop behavior remain the same.
- Web ad slots, sticky desktop rails and hover states do not exist in native layout; editorial content and all server requests remain present.
- The live Watch channel detail is owned by the native LiveKit screen and is not duplicated in this portal screen.
- Native playback requires the existing `react-native-video` dependency; no additional package is assumed.
